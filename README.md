# Sfera cava — video originale 1440p

2560 × 1440, 60 fps, 32 secondi. Il video è diviso in due parti per il download tramite GitHub.

## Windows

1. Scarica lo ZIP di questo ramo.
2. In Esplora file, clic destro sullo ZIP → **Estrai tutto**.
3. Apri la cartella estratta e fai doppio clic su **APRI-VIDEO.cmd**.

Il comando unisce i due file, verifica il video con SHA-256 e lo apre nel lettore predefinito. Usa soltanto file locali e strumenti di Windows.

Il file **Sfera-cava-loop-1440p-60fps.mp4** rimane nella stessa cartella; puoi importarlo in Wallpaper Engine.
