# Backup completo

Le sei parti ricostruiscono lo ZIP originale di 110068458 byte, contenente 892 file.
Scarica l'intero repository ed estrailo prima di ricreare lo ZIP.

- Windows: doppio clic su **Ricrea-ZIP.cmd**.
- Con Python: `python backup/ricrea_zip.py` dalla cartella principale.

Le parti devono rimanere nella stessa cartella. Il comando le unisce in ordine,
senza modificare i file dell'applicazione. Il programma Python verifica anche
lo SHA-256 del risultato.
